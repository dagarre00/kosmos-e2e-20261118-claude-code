# workflow-init

You are task `T-001`, the bootstrap: it is not claimed with `state.mjs claim` (step 3 makes its branch). Create no files beyond those named here. With no code yet (greenfield), an empty `verify_cmd` is expected: docs-only tasks (wiki, Markdown, `.gitignore`, `.gitattributes`, `.env.example`, a deleted `scripts/preview.mjs`) still pass `state.mjs test`, and the first code task must set it. Never touch application code, the project's existing CI, or existing lines in config files; append only. The template's own `.github/workflows/workflow.yml` is part of the template, not existing CI. Never stash, reset, clean, print secret values or add dependencies.

1. **Git.** No repository → `git init`, commit all files as `chore: import workflow template`. Stop with `BLOCKED: <exact cause>` on: dirty tree (if you just copied the template into an existing repo, tell the user to commit the copy first), merge in progress, detached HEAD, unreachable configured remote, Node older than 18, more than one independently deployed app.
2. **Detect** (never assume `src/`; do not read module bodies): languages, package manager, source roots, default branch, remotes, `.env*` file names, env reads in the source roots, instruction files, other agent adapter directories and their read-list config files, whether there is a user interface.
3. **Branch.** Integration is `develop` if it exists, else the default branch. Work on `chore/init-workflow` from it.
4. **Resolve** every double-brace token in `AGENTS.md`, `DEPLOY_INVENTORY.md` and the frontmatter of `wiki/infra/00-stack.md`, then delete the template note in `AGENTS.md`:
   - `{{SOURCE_ROOTS}}`: detected roots (backticked in prose). No code yet → ask the human where it will live.
   - `{{DEFAULT}}`, `{{INTEGRATION}}`: branch names. When they are the same branch, name it once in prose (`Never commit to main`).
   - `{{INSTALL_CMD}}`: the lockfile install CI needs before `verify_cmd` (`npm ci`, `pip install -r requirements.txt`); none needed → leave `install_cmd:` empty.
   - `{{VERIFY_CMD}}`: the existing full check chain (lint, type-check, tests), quiet reporter. No tests → leave `verify_cmd:` empty, add the row `H-002 | Set verify_cmd in wiki/infra/00-stack.md once tests exist | open` and emit it as `HUMAN_TODO`; do not invent a test setup.
   - `{{TEST_GLOB}}`: git pathspec globs matching the test files, such as `**/*.test.*` or `tests/**`.
5. **Seed**, inventing nothing:
   - `wiki/infra/00-stack.md` body, from manifests only: runtime and versions, each dependency with its purpose, build, run and test commands, top-level layout, files not regenerable from text and where each comes from.
   - `wiki/contracts/components/00-modules.md`: one row per top-level module, purpose from names and exports.
   - `wiki/product/00-product.md`: facts found in the repo; keep `WIKI_GAP: <detail>` for the rest.
   - `DEPLOY_INVENTORY.md` and `.env.example`: detected environments, services and env variable names, never values.
   - **Base context.** Ask once whether there is a brief, PRD or product prompt. A pasted one is saved verbatim as `BRIEF.md` at the root; a file path stays where it is. Copy only its stated product facts into `00-product.md` with a `Source: <path>` line, keep `WIKI_GAP` for the rest, and append `- [ ] T-002 | seed-backlog | [S] | docs | wiki/product/00-product.md | — | plan-backlog done: product page locked, draft feature pages and folder indexes, ordered TODO lines with after: deps; WIKI_OK` to `TODO.md`. No brief → append the same line only if the human wants a backlog seeded later.
6. **Adapters.** `.gitignore` and `.gitattributes`: append missing lines from the template's (including `.worktrees/`); skip `.env.*` if such a file is tracked. No user interface → delete `.agents/skills/ui-mockup/`, `scripts/preview.mjs` and `wiki/contracts/ui/`. Then `node scripts/adapters.mjs --write` updates the `.claude/` and `.dsh/` pointers (delete an adapter directory the project will not use first). Another agent adapter directory exists → mirror the template's thin skill pointers there by hand (each reads the canonical `.agents/skills/<name>/SKILL.md`) and report it: `adapters.mjs` does not know it. A read-list config exists → add `AGENTS.md` to it. If instruction files existed before the copy, keep their text, report overlaps, and stop to ask on a conflict.
   - **CI and hooks.** Not hosted on GitHub → keep `.github/` and add the next free `H-XXX | Port .github/workflows/workflow.yml to <host>: run the self-tests, node scripts/adapters.mjs and node scripts/state.mjs ci on every push and PR, full history | open`. The runtime `verify_cmd` needs beyond Node (a language toolchain) → add its setup step to `.github/workflows/workflow.yml` before `Gates`. Another hook manager (`core.hooksPath` set, `.husky/`, `lefthook.yml`, `.pre-commit-config.yaml`) → add a pre-push entry running `node scripts/state.mjs pre-push` to it and report it; else `state.mjs claim` enables `.githooks/` in each clone.
7. **Check.** No `{{` left in `AGENTS.md`, `DEPLOY_INVENTORY.md` or `wiki/`. Then run every `--self-test` in `scripts/`, `node scripts/adapters.mjs`, `node scripts/verify-wiki.mjs --check-env --check-debt --check-coverage` and the verify command. Each exits `0` or is reported with its exact `BLOCKED` cause. Never add `env-ignore` to application code; report those lines.
8. Tick `T-001`, commit `chore(T-001): initialize workflow`, never merge. Report in ≤ 200 words: resolved tokens, stack, adapters, every `HUMAN_TODO` (always `H-001`: branch protection requiring the CI `check` job) and `WIKI_GAP`, the `COVERAGE` line, the command to open the PR, and that `/next-todo` works only after the init PR merges.
